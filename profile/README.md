# EcoCycling ♻️

**EcoCycling**은 친환경 자원 순환, 비전 AI 기반 재활용 쓰레기 자동 분류, 현장 모니터링 및 스마트 키오스크/프린터 제어 시스템을 연구하고 구축하는 프로젝트 그룹입니다.

---

## 📌 주요 프로젝트 (Key Projects)
- **`waste-sorting-system`**: 딥러닝 기반 재활용 쓰레기 실시간 객체 탐지 및 분리수거 제어 시스템
- **`Ecocycling-Client`**: 스마트 수거 키오스크 및 사용자 인터랙션 프론트엔드 클라이언트
- **`Ecocycling-Server-Code`**: 수거 데이터 수집, 포인트 정산 및 사용자 계정 관리 백엔드 API
- **`Printer-Server-Program`**: 현장 영수증 및 라벨 자동 출력 프린터 제어 서버
- **`tourist-attraction-big-data-processing-code`**: 관광지/도심 내 폐기물 배출량 시계열 빅데이터 분석 및 예측 파이프라인
